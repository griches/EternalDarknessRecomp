Eternal Darkness Recomp - Linux x86-64 / Steam Deck
===================================================

This folder holds no game. It turns your own copy of Eternal Darkness:
Sanity's Requiem into a native Linux game.

1. Put your disc image here: an .iso or .gcm of the European (GEDP01)
   GameCube disc. The USA disc is not supported.
2. Run play.sh. On a Steam Deck, in Desktop Mode: Steam > Add a Non-Steam
   Game > Browse > this folder > play.sh. Then play it from Game Mode.

The first start translates your disc and builds the game from it, which
takes about half a minute on a Steam Deck. After that it starts straight
away. If you swap in a different disc image it builds again.

Saves, settings and logs stay in this folder (saves/, settings.ini,
ed-*.dolcard, logs/).

HD textures (recommended)
-------------------------
Download both, unpack them, and put the two folders in a folder called
"textures" in this folder. On a Steam Deck, Ark (in Desktop Mode) opens the
.7z file.

- Eternal Darkness HD Texture Pack by Zombie (DDS, 2.9 GB .7z, on Mega):
  https://mega.nz/file/6m5TQToI#v09Y_gYdtZ24WTT6BlfCeM5uvw1nRs3QozcYZkUVVqg
- PAL supplement, the European disc's screens and words the pack misses
  (DDS, 10.7 MB .zip):
  https://www.bouncingball.mobi/eternaldarkness/files/ED-PAL-supplement-dds.zip?v=2

Leave both folders as they are; the supplement wins where they overlap.
Options > Game > HD textures turns them on and off.
